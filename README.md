# 🏨 Hotel Management System

A complete Hotel Management System that enables administrators to manage bookings, rooms, customers, and staff efficiently. This system is suitable for hotels, resorts, or lodges looking to digitize daily operations.

---

## 🔧 Tech Stack

- **Backend**: Java / Spring Boot 
- **Database**: PostgreSQL 
- **Authentication**: JWT / OAuth2 / Session-based
- **DevOps**: Docker / AWS

---

## ✨ Features

### 👨‍💼 Admin Panel
- Add/update/delete rooms, room types, and pricing
- View all bookings and manage statuses
- Manage users (staff/customers)
- Generate booking and financial reports

### 🧑‍💼 Staff Dashboard
- Update availability status

### 🧑‍💻 Customer Portal
- Register/login to book rooms
- Search rooms by date, type, and price
- Cancel or modify existing reservations

### 📊 Other Features
- Role-based access control (Admin, Staff, Customer)
- Real-time availability checking
- Payment gateway integration
